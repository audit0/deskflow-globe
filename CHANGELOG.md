# Changelog

## 1.0.0 — 2026-10-01

- Switch enabled macOS keyboard layouts with a short isolated Fn/Globe tap.
- Keep the observer ahead of Deskflow after server restarts through optional user autostart.
- Portable per-user installation and reversible removal; LangSwitch replacement is opt-in.
- Universal Apple Silicon/Intel build, checksums, and CI regression/build checks.
- Document Secure Input recovery and the limits of physical-hardware validation.
